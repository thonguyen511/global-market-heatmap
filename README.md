# Global Market Heatmap 🌍

A beautiful, interactive 3D WebGL visualization of global financial markets utilizing Three.js and automated backend data scraping.

## Overview
This project provides an interactive 3D visualization of the Earth and Moon. Global financial markets are plotted across the globe, with their indicators dynamically changing color in real-time based on actual UTC market hours and holidays. 

Users can explore the data by interacting with specific countries to view their TradingView stock heatmaps, or by clicking the orbiting Moon to dive into the global cryptocurrency market.

## Features
- **3D Globe & Moon**: Built natively with Three.js. Features highly realistic textures, orbital mechanics, and dynamic day/night cycles synchronized to simulated or real time.
- **Live Market Hours**: Market dots update their color seamlessly based on their real-world open/close UTC schedules (Green = Open, Red = Closed, Blue = Holiday).
- **Top Time Marquee**: A continuous scrolling marquee tracking the real-world time across major global financial hubs.
- **Automated Python Scrapers**: Includes robust Playwright scripts (`scrape.py` and `scrape_crypto.py`) that run headlessly to navigate TradingView, enable dark mode, and download high-resolution market heatmaps into the local cache.
- **Smart Interactions**:
  - **Earth Interaction**: Hover over any market dot for a quick peek, or left-click to pin the Heatmap UI open.
  - **Moon Interaction**: Click the moon to explore the global cryptocurrency market (no hover effect).

## Technology Stack
- **Three.js**: 3D WebGL rendering, orbit controls, camera math, and custom shaders.
- **D3.js**: Equirectangular projection of GeoJSON data to map country borders onto the globe.
- **date-holidays**: Backend Node.js library utilized to autogenerate accurate worldwide market holiday schedules.
- **HTML/CSS/JS**: Pure Vanilla JS, styled elegantly with CSS backdrops and micro-animations.

## Running Locally

You can run this project easily using Docker!

### Using Docker
1. Build the image:
```bash
docker build -t global-market-heatmap .
```
2. Run the container:
```bash
docker run -p 8080:80 global-market-heatmap
```
3. Open your browser and navigate to `http://localhost:8080`.

### Without Docker (Node.js)
If you prefer running it locally with Node.js:
```bash
npx serve .
```
